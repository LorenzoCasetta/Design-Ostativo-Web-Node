# Web Node 1

Il prototipo originale: un solo file HTML con la mappa a nodi di inps.it, ridisegnata a partire dalla struttura del sito.

- 85 nodi su quattro livelli, dalla home alle singole schede.
- Ricerca per nome e schema completo, aperto dal triangolo.
- Vista affiancata, aperta dal quadrato: il sito a sinistra, la mappa a destra. Il sito è una riproduzione statica della home INPS, perché quello reale non può essere incorporato in un frame.
- Dalla vista affiancata la mappa si può staccare in una finestra sopra il sito.

Funziona solo offline: scaricare [`index.html`](index.html) e aprirlo nel browser.
